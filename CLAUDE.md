## Design system

- **Style:** retro pixel / 8-bit game UI and Windows XP windows, mixed with scrapbook / collage / polaroid. "Playful but not cluttered."
- **Colours:** cream #FFFBE0 (main reading area), paper #FFFEF6, blue #2994B2 (cover and contact), ink #113F59 (lines, text, shadows), ink-2 #284C5F, yellow #FFB400 (main accent), sand #F4CCA5, orange #EA8818 (tiny touches). Ratio roughly 60 cream / 30 blue-ink / 10 accent. Blue stays the primary; mode colours are accents for unity.
- **Fonts:** Silkscreen for big English pixel headings only (stroke plus hard shadow). Prompt for everything else, including all Thai.
- **Lines:** 2px ink borders below the cover (thicker on the cover), hard ink shadows with no blur, square corners.
- **Pixel icons:** 12×12 sprites drawn in `SPRITES` in app.js.

## Workflow

- Develop on the branch the session gives you. One PR per round of feedback. The owner reviews the Cloudflare preview, then merges.
- After a merge, restart the branch from `origin/main` and use `--force-with-lease`.
- No commits or PRs unless the owner's request implies them (each round so far: commit, push, open or update the PR).
- No model names or IDs in commits, PRs or code.
- **Testing:** `python3 -m http.server 8765` in `public/`, then Playwright (pre-installed) on desktop 1440×900 and mobile 390×844. Check for `pageerror`, look at screenshots, and send them to the owner. `node --check public/app.js` after JS edits.
- **TikTok covers for new clips:** fetch the oEmbed thumbnail, save it as `images/thumbs/tt-<id>.jpg` at 540px wide. Slide images are cropped square into `images/thumbs/`.
- **YouTube covers:** YouTube's auto `hqdefault` has black bars that show in square tiles. Save `maxresdefault` at 960×540 as `images/thumbs/yt-<id>.jpg` and set `thumbnail:` on the work (used by the tile and the player facade; the check page counts it as an auto cover).
- **Custom covers flow:** the owner designs every cover in one Canva design named `Iggy Portfolio Covers` (800×800, one page per cover). The owner orders pages freely, so match each page to a work by looking at it (ask if unsure) and record the page in the "หน้า Canva" column of the checklist in `public/images/covers/README.md`. When the owner says which pages are done, find the design with the Canva connector (`search-designs`), `export-design` those pages as JPG, save each as `images/covers/<slug>.jpg` (800×800, ≤150 KB), tick "ขึ้นเว็บ" in the checklist (🙈 = hidden work), run the Playwright check, send screenshots and push to the round's PR. Fallback: the owner drops JPGs in chat with page numbers. Don't ask the owner to upload to GitHub. The safe-zone guide is `design/cover-guide-800.png` (outside `public/`, so not deployed): the corner badge covers about 28%×20% of a tile on desktop and up to 45%×30% on mobile.
- When a change affects how the owner edits (new content.js key, new image folder or size), update `HOW-TO.md`, the folder README, the check page and this file in the same PR.
