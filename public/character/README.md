# ตัวละครบน Cover

วางไฟล์ตามชื่อในตาราง เว็บจะหยิบไปใช้เอง **ไม่ต้องแก้โค้ด**
ไฟล์ไหนยังไม่มี เว็บจะข้ามไป (ไม่พัง)

## โครงสร้างโฟลเดอร์

```
public/character/
├── base.png            ← ตัวละครท่าหลัก ชุดปกติ (ตอนเปิดเว็บ)
├── base-2.png          ← (ไม่บังคับ) เฟรมกะพริบตา/ขยับปาก สลับกับ base.png
├── video/              ← ชุด "Video Editing & Production"
│   ├── base.png        ← (ไม่บังคับ) ท่าใหม่ทั้งตัวสำหรับชุดนี้ ถ้าไม่มีจะใช้ base.png หลัก
│   ├── base-2.png      ← (ไม่บังคับ) เฟรมกะพริบตาของท่านี้
│   ├── 1.png           ← ชิ้นส่วนชุด ชิ้นที่ 1 (บินมาแปะก่อน)
│   ├── 2.png
│   └── ... ถึง 6.png
├── animation/          ← ชุด "Animation" (โครงเหมือน video/)
├── graphic/            ← ชุด "Graphic Design" (โครงเหมือน video/)
└── icons/              ← (ไม่บังคับ) ไอคอนบนปุ่มเลือก เช่น video.png
```

## สเปกไฟล์

| เรื่อง | ต้องเป็นแบบนี้ |
|---|---|
| นามสกุล | `.png` (หรือ `.webp`) **พื้นใส** |
| ขนาด | **ทุกไฟล์ขนาดเท่ากัน** แนะนำ 1024 × 1024 px (เท่ากับ base.png ตอนนี้) |
| วิธี export | วาดในไฟล์เดียวแยกเลเยอร์ แล้ว export ทีละเลเยอร์ **เต็มผืน ห้าม crop** ชิ้นส่วนจะซ้อนตรงตำแหน่งพอดี |
| ลำดับซ้อน | 1.png อยู่ล่างสุด 6.png อยู่บนสุด (เช่น 1 = เสื้อ, 2 = หมวก, 3 = ของในมือ) |
| จำนวนชิ้น | ชุดละ 1–6 ชิ้น |
| ขนาดไฟล์ | ไม่ควรเกิน 300 KB ต่อไฟล์ (pixel art ส่วนใหญ่เล็กอยู่แล้ว) |

## วิธีอัปโหลด (บนคอม)

1. เข้า github.com/IggyKiminoto/Iggy-Portfolio → `public` → `character`
2. ถ้าจะใส่ชุด: เข้าโฟลเดอร์ชุด เช่น `video` (ถ้ายังไม่มีโฟลเดอร์ ดูข้อ 4)
3. **Add file** → **Upload files** → ลากไฟล์ลงไป → **Commit changes**
4. สร้างโฟลเดอร์ใหม่: ตอนอัปโหลด ให้ลากโฟลเดอร์ `video` ทั้งโฟลเดอร์ (ที่มีไฟล์ 1.png ข้างใน) ลงไปได้เลย GitHub จะสร้างโฟลเดอร์ให้
5. รอ 1–2 นาที แล้วกดปุ่มบนเว็บดูผล

## สี / ข้อความ / ชื่อปุ่ม ของแต่ละชุด

แก้ใน `public/content.js` ส่วน `modes` (สี `colors`, คำพูด `line`, ชื่อปุ่ม `label`)
