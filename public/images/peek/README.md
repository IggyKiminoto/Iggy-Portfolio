# รูปที่ "โผล่" ออกจากโฟลเดอร์

วางรูปปกงานไว้ที่นี่ แล้วรูปจะโผล่ออกจากปุ่มโฟลเดอร์ (ทั้งบน Cover และในส่วน ALL WORK)
ถ้ายังไม่มีรูป เว็บจะใช้การ์ดไอคอนพิกเซลแทน

| ชื่อไฟล์ | โผล่จากโฟลเดอร์ |
|---|---|
| `graphic-1.jpg` `graphic-2.jpg` `graphic-3.jpg` | Graphic |
| `video-1.jpg` `video-2.jpg` `video-3.jpg` | Video |
| `animation-1.jpg` `animation-2.jpg` `animation-3.jpg` | Animation |

- ใช้ `.jpg` `.png` หรือ `.webp` ได้
- แนวตั้ง 3:4 สวยสุด เช่น 600 × 800 px
- ไม่ควรเกิน 150 KB ต่อรูป
