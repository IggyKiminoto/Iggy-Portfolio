# วางรูปที่นี่ (อัปจากมือถือได้)

เว็บจะหยิบรูปในโฟลเดอร์นี้ไปแสดงเอง **แค่ตั้งชื่อไฟล์ให้ตรง** ไม่ต้องแก้โค้ด

| ชื่อไฟล์ | ไปโผล่ตรงไหน |
|---|---|
| `profile.jpg` | รูปโปรไฟล์ในส่วน About |
| `about-1.jpg` ถึง `about-12.jpg` | รูปกิจกรรม (MOMENTS) ใต้ส่วน About เรียงตามเลข |

ใช้นามสกุล `.jpg` `.jpeg` `.png` หรือ `.webp` ได้

## วิธีอัปโหลดจาก iPhone

1. เปิด **Safari** (ไม่ใช่แอป GitHub — แอปอัปโหลดไฟล์ไม่ได้) แล้วเข้า github.com/IggyKiminoto/Iggy-Portfolio
2. ถ้าไม่เห็นปุ่ม **Add file** ให้กด **aA** ที่ช่องที่อยู่เว็บ → **Request Desktop Website**
3. เข้าโฟลเดอร์ `public` → `images`
4. กด **Add file** → **Upload files** → **choose your files** → เลือกรูปจาก Photos
5. **ตั้งชื่อไฟล์ให้ตรงก่อนอัป** (ในแอป Files เปลี่ยนชื่อได้) หรืออัปแล้วไปเปลี่ยนชื่อทีหลังก็ได้
6. เลื่อนลงกด **Commit changes** → รอ 1–2 นาที เว็บอัปเดตเอง

## เปลี่ยนรูป

อัปไฟล์ใหม่ด้วย **ชื่อเดิม** ไฟล์เก่าจะถูกแทนที่

## ลบรูป

กดเข้าไฟล์ → กดจุดสามจุด (…) → **Delete file** → **Commit changes**

## ข้อควรรู้

- รูปจาก iPhone ที่เป็น `.heic` เว็บแสดงไม่ได้ ตั้งค่า: Settings → Camera → Formats → **Most Compatible** (หรือส่งต่อรูปเป็น JPG ก่อน)
- รูปไม่ควรเกิน 2 MB ต่อรูป หน้าเว็บจะโหลดเร็ว (แอปย่อรูปหรือแคปหน้าจอรูปก็ช่วยได้)
- รูปกิจกรรมแสดงสวยสุดเป็น **แนวตั้ง 4:5**
- อยากใส่คำบรรยายใต้รูป แก้ที่ `galleryCaptions` ใน `public/content.js`
- ถ้าเว็บพัง: Cloudflare → Workers & Pages → โปรเจกต์ → Deployments → … → **Rollback**
